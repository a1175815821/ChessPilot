# ChessPilot 设计规范 v1.0

> 适用范围：伴侣 App 控制页（MainActivity）与常驻悬浮窗（OverlayManager）。
> 实现约束：纯 framework 控件、无新增依赖、深色优先；所有既有**文本契约**
> （横幅标题前缀守卫、按钮文案、胜率三档色、狂暴红/远程绿）保持不变。

## 0. 设计原则

1. **对局优先**：打开 App 第一眼必须回答三件事——引擎活没活、推荐走哪步、我胜率多少。
   诊断信息（Hook/NNUE/心跳）永远让位于此。
2. **一屏一焦点**：状态（看）与设置（改）分卡；高频开关平铺，低频参数折叠。
3. **色彩有语义**：金色 = 品牌与主操作；绿/黄/红 = 胜率三档（唯一出处 `ChessMath`）；
   红框 = 狂暴、绿框 = 远程算力。任何装饰性用色不得与语义色冲突。
4. **动效即反馈**：只用于表达状态变化（展开/按压/计算中），时长 ≤ 250ms，不喧宾夺主。

## 2. 字体排版

字体族：中文/西文用系统默认（`sans-serif`）；**招法、FEN、日志、深度读数**用 `monospace`。

| 层级 | 字号/字重 | 用途 |
|---|---|---|
| Display | 30sp Bold Mono | 最佳招法（如 `e2e4`） |
| Title | 20sp Bold | 页面标题 ChessPilot |
| Section | 15sp Bold | 分组卡标题 |
| Body | 14sp | KV 值、按钮、列表正文 |
| Caption | 12sp | 辅助说明、KV 标签 |
| Micro | 11sp | 角标、版本号、脚注 |

行高：正文 1.45；日志 1.35。数字与招法一律等宽，禁止斜体。

---

## 3. 间距与栅格

- **4dp 基线网格**，间距阶梯：`4 / 8 / 12 / 16 / 20 / 24 / 32`
- 页面边距 16；卡片内边距 16；卡片间距 12；分组间距 20
- 圆角：卡片 16dp；按钮/输入框 12dp；chip 与角标 8dp；悬浮窗 20dp；徽标 6dp
- 触控目标 ≥ 44dp（开关行、分段控件整行可点）
- **响应式**：内容列最大宽度 560dp，超出居中；悬浮窗最大宽度 = 屏宽 − 32dp；
  横屏/平板下单列居中，不拉伸卡片。

## 4. 组件规范

### 4.1 页面骨架（控制页）

```
┌ Header：♞ 金底图标 + ChessPilot/副标题 + 版本 chip
├ 对局雷达卡（Hero）
│   状态点+引擎状态 ………… 模式角标(狂暴/算力)
│   最佳招法 Display Mono   │ FEN 小棋盘 112dp
│   胜率(语义色)+深度+时间   │
├ 连接与引擎状态卡：KV 行 ×8（Hook/NNUE/引擎/后端/局面/思考/自动/心跳）
│   错误行：danger 色高亮整行
├ 快捷操作：主按钮(启动/停止) + 次按钮×2(打开多邻国/悬浮窗授权)
├ 功能设置卡（默认展开）：开关行 ×3（自动走棋/狂暴/极限思考）
├ 高级设置卡（折叠）：滑杆行 ×3 + 分段控件 + IP/端口 + 远程滑杆 ×2 + 测试按钮
├ 最近事件卡（折叠）：终端风格日志（bg/inset + mono 12sp，高 220dp）
└ 脚注：GPL-3.0 · 仅供研究 · ToS 提示
```

### 4.2 按钮

| 类型 | 样式 | 用途 |
|---|---|---|
| Primary | 金底 `brand/gold` + `on-gold` 14sp Bold，圆角 12，高 48dp | 启动引擎服务 |
| Danger-Outline | 透明底 + `danger` 1.5dp 描边 + `danger` 文字 | 停止引擎服务 |
| Secondary | `bg/elevated` 底 + hairline 描边 + `text/primary` | 打开多邻国/悬浮窗授权/测试远程连接 |
| Ghost-Disabled | `#2A3342` 底 + `text/tertiary` | 悬浮窗「自动」等禁用态 |

按压：alpha 0.85 + 缩放 0.98，100ms。

### 4.3 开关行

整行 44dp+，左：标题 14sp + 说明 12sp（`text/tertiary`）；右：Switch。
开启：轨道 `brand/gold-dim`、拇指 `brand/gold`；关闭：轨道 `#2A3342`、拇指 `#6B7686`。
风险开关（自动走棋）开启时说明文字转 `semantic/mid` 警示色。

### 4.4 滑杆行

标题行：左 label 14sp，右**数值 chip**（mono 12sp，金底 16% + 金字，圆角 8）。
轨道 `#2A3342`，已选段与拇指 `brand/gold`。被禁用（固定深度生效时）整体 alpha 0.4。

### 4.5 分段控件（算力后端）

外壳：`bg/inset` + hairline，圆角 12，高 40dp，三等分。
选中段：`brand/gold` 底 + `on-gold` 13sp Bold；未选：透明 + `text/secondary`。

### 4.6 状态点

8dp 圆点 + 状态文字 17sp Bold。「启动中/计算中」时 1s 呼吸脉冲（alpha 1→0.35 往返），
稳态不动画。

### 4.7 FEN 小棋盘

112×112dp，圆角 10，hairline 描边。格色：亮 `#C7D2E8` / 暗 `#5A6B8C`；
白子 `#FAFAFA`、黑子 `#161616`，Unicode 棋子字形 0.72 格高。
右下角 6dp 圆点标示行棋方（白=实心白，黑=实心黑+白描边）。FEN 非法时显示空棋盘，不崩溃。

### 4.8 悬浮窗横幅

- 容器：`#EB141A22`（92% 不透明），圆角 20，hairline 描边；模式态描边 2dp（狂暴红/远程绿，远程优先）
- 布局：`[模式角标] [spinner] [标题+副行(weight 1)] [走棋按钮]`，内边距 12×10
- 标题 16sp Bold `text/primary`；副行 13sp（胜率时按语义色，其余 `text/secondary`——B1 纪律）
- 走棋按钮：全圆角 pill，高 36dp，金底深字（启用）/ `#2A3342` 灰字（禁用「自动」）
- spinner：金色 270° 圆弧，1 rev/s
- 入场：fade + 上移 8dp 回位，180ms；拖拽纯偏移（现状保留）

## 5. 交互动效

| 场景 | 参数 |
|---|---|
| 分组展开/折叠 | `LayoutTransition` 200ms；chevron 旋转 ±90° 200ms |
| 按压 | alpha 0.85 + scale 0.98，100ms |
| 状态点脉冲 | alpha 1↔0.35，1000ms 往返，仅「启动中/计算中」 |
| 悬浮窗入场 | alpha 0→1 + translationY −8dp→0，180ms ease-out |
| 开关/滑杆/分段 | 系统默认 150ms 内插值 |

原则：无循环装饰动画（spinner 与脉冲除外，二者皆承载语义）；数值每秒刷新不做补间。

---

## 6. 信息层级与契约（不可破坏）

1. 横幅标题前缀：`推荐 / 自动走棋中 / 等待走棋中 / ChessPilot / 局面停滞` 是
   `clear()` 的守卫名单；求助态 `升变请手动选皇后 / 请手动走棋` 由标题直显。
   **文案一字不可改。**
2. 副行颜色是状态：写结论才上语义色，`正在计算…` 等过程态必须复位灰（B1）。
3. 走棋按钮文案仅 `走棋 / 自动`；按钮是横幅唯一触点，本体只吃拖拽。
4. 胜率三档阈值（0.6/0.4）与色值唯一出处 `ChessMath`，UI 不得另设。
5. 模式角标优先级：远程 > 狂暴；角标只改样式，不改标题文本。
