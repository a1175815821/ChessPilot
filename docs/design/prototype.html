本次重设计解决的问题

· 状态从一整块等宽灰字 → 分层卡片，招法/胜率一眼可读
· FEN 字符串 → 可视化小棋盘 + 行棋方指示点
· 默认紫色系统控件 → 统一金色选中体系（开关/滑杆/分段）
· 后端「禁用即选中」的按钮 hack → 标准分段控件
· ▶/▼ 文本折叠 → 旋转 chevron + 200ms 高度动画
· 悬浮窗默认按钮 → 全圆角 pill，禁用态有独立灰阶样式
